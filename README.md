# Omani Essence — Luxury Motion Edition

React + Vite + TypeScript + Tailwind + Motion + lucide-react.

## Local run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
Upload `dist/` to a static host or import the entire project into Bolt.

## Features
- Luxury dark/amber design with spring-powered cursor glow and animated cards
- Dedicated promotions and featured bestseller sections (demo selections; not real sales figures)
- Fragrance categories and conceptual scent notes
- Product detail modals and responsive product catalogue
- Demo display name saved only in localStorage, no authentication
- Working localStorage shopping cart; no real payments
- Responsive mobile navigation

## Notes
Images are locally included and work offline, but the original source images are low resolution (~260px wide for most product crops). Replace with licensed or generated 1000px+ square photos for truly crisp desktop closeups.
All products, ingredients, offers, ratings, accounts and contact details are fictional student-project content. No real sales or checkout.
